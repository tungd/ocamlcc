# Perceus ARC & Freestanding Slab Allocator

Phase 2 replaces libc `malloc`/`free` with a freestanding slab allocator and static Perceus reference counting with zero-leak error-return exceptions and weak references.

## Freestanding Slab Allocator & Thread Safety (`runtime/arc.c`)
- **Size classes**: 12 classes from `16` to `2048` bytes (`16, 32, 48, 64, 96, 128, 192, 256, 384, 512, 1024, 2048`) backed by `64 KB` slabs obtained from `pal_page_alloc`, with per-class LIFO free lists protected by `g_alloc_lock` (C11 `ArcSpinLock`). All slots are 16-byte aligned (even user pointers, preserving the bit-0 immediate tag invariant).
- **Atomic refcounts & counters**: `ArcHeader.refcount` is `_Atomic uint32_t`, updated via C11 `<stdatomic.h>` (`arc_retain`, `arc_release`, `arc_drop_reuse`, `drop_child_val`, `arc_alloc_array`, plus CAS-based `arc_try_retain` for weak-ref upgrades); `g_live_objects`, `g_reuse_hits`, and `g_next_oo_id` are `_Atomic int64_t`.
- **Large blocks**: allocations `> 2048` bytes round up to `16 KB` page alignment and release directly via `pal_page_free`.
- **O(1)-stack tail drop**: `release_subtree` tail-iterates on the last dying child (`tail`) and uses a `256`-entry stack buffer plus lazy `pal_page_alloc` overflow pages (`DropPage`) for deep non-tail trees. `cc_roots_add` is invoked before `atomic_fetch_sub` when `rc > 1`, preventing any race with a concurrent final drop.

## Middle-End ARC Pass (`lib/arc_pass.ml`)
- **Ownership**: `Let`-bindings and function parameters start owned (`+1` rc); `Pure` global functions and static literals/immediates omit refcount traffic; closure captures (`env`), self-refs, and `LetJoin`/`While`/`For` outer references are **borrowed** (with `frame_borrowed` distinguished so exceptional unwinding cleans them up cleanly).
- **Pure-defs analysis** (`Anf.pure_defs`, shared by `arc_pass` and `codegen`): a function (or whole mutual `let rec` group) whose free variables are only its own parameters plus already-collected pure functions is an immortal static function — its binding gets no refcount traffic (no `Release`, no `DropReuse`), and codegen defines it with `has_closure = false` and groups mutual tail calls into trampoline SCCs. The analysis recurses into function bodies and every branch/join region (`LetJoin` rhs, `If`, `Switch`, `TryWith`, `While`, `For`, `StaticCatch`), so non-capturing helpers nested inside other functions are static too; a spine-only walk used to own+release them, forcing codegen to synthesize an immortal `clos.N` wrapper purely to feed `arc_release_val`. Regression-tested in `test/pure_nested_test.ml` (fronted through `Frontend.compile_implementation`, asserting non-capturing funs are never `Release`d).
- **Field & mutation balance**: `Field`/`ArrayGet` retain loaded values; `SetField`/`ArraySet`/`Assign` release overwritten values; a `MutLet` slot is released exactly once, where it leaves scope (function-exit `Halt`, `Raise`, or `StaticRaise` to a narrower handler).
- **C-call ABI registry** (`lib/ccalls.ml`): every C external lowered to `Ccall` is classified in one typed table — `argc`, `raises` (stores to `ocamlcc_exn_slot`, so call sites inside `TryWith` get `CheckExn` unwinding), and `yields` (can suspend the fiber, so call sites join the shadow-stack protocol). `anf.ml`'s external lowering consults it: registered `caml_*` primitives lower to `Ccall`, unknown `caml_*` primitives are rejected at compile time, and unknown non-`caml_` externals (user C FFI) get the conservative default `raises = true; yields = false` — one dead branch if never raised, but never a silently missed unwind. The old hardcoded `ce_may_raise_fn`/`is_yielding_ccall` name lists (which drifted — `Weak.get_copy` was missed once) are gone; `runtime/arc.c`'s `caml_blit_bytes`/`caml_blit_string`/`caml_fill_bytes` raise `Invalid_argument "index out of bounds"` on out-of-bounds (like real OCaml) instead of `pal_abort`, and are registered as raising. ABI contract pinned by `test/ccalls_test.ml`; end-to-end by the `invarg=` probes in `examples/stdlib_test.ml`.
- **Comparison contract** (`val_compare_raw` in `runtime/arc.c`): structural comparison is bounded — a C-recursion depth limit (50 000) plus a shared step budget (10⁸) raise `Invalid_argument "compare: cyclic structure"` instead of smashing the stack on cyclic records or spinning forever on tail-cyclic lists. Exception-constructor id blocks (tag 248: field 0 = name string, field 1 = OID) compare **structurally** (name string, then OID) like real OCaml, deterministically, instead of by raw heap address. `pipe`/`fd_read`/`fd_write` raise on failure (`Sys_error "pipe failed"` / `Invalid_argument "index out of bounds"` on out-of-bounds reads/writes) instead of `pal_abort`, and are registered `raises = true` in the C-call ABI registry so `TryWith` unwinds correctly; OS errors on read/write still return the negative count for the Fiber I/O machinery to poll.
- **Mutable-slot scope invariant**: `Halt`s that flow into a `LetJoin` rhs, `While`/`For` condition/body, or a loop-exit continuation are *not* scope exits, so they must not emit `ReleaseMut` for slots that remain in scope. `env.no_release_muts` (set to `env.muts` when descending into those regions) defers such slots to the continuation that still uses them; `Halt` releases `env.muts - env.no_release_muts`. Muts introduced *inside* the region still release at its own `Halt`. Regression-tested at the middle-end level in `test/arc_mutlet_test.ml` (drives hand-written `Lmutlet` Lambda terms — the frontend emits none today; see below — through `Anf.of_lambda` + `Arc_pass.run` and counts `ReleaseMut` per slot).
- **Lmutlet latency**: OCaml 5.5's frontend never emits `Lmutlet`/`Lmutvar` into `Lambda.program` (local `let mutable` is not source syntax; `Tmc.rewrite` and `eliminate_ref` run only in the backends ocamlcc does not use), so `MutLet` ANF nodes are currently unreachable from source. If `[@tail_mod_cons]` support or local-mutable lowering is added to `lib/frontend.ml`, the `test/arc_mutlet_test.ml` invariant guard must stay green.
- **In-place reuse**: `DropReuse` pairs dead unique heap blocks with downstream `AllocReuse` (even across `If` and `CheckExn` via `FreeReuse`).

## Zero-Leak Exceptions, Cycle Collection & Weak Clearing
- **Thread-local error-return channel**: `tls_exn_slot` (`_Thread_local int64_t`, accessed via `ocamlcc_get_exn` / `ocamlcc_set_exn`) carries raised exception blocks per OS thread (swapped per fiber on `fiber_swap_to`); `CheckExn`/`Unwind` execute local frame cleanup before branching to enclosing `TryWith` handlers or returning `1` to callers. `ce_may_raise_fn` treats `App`, yielding `Ccall`s, `Weak` `Ccall`s, total-order comparison `Ccall`s (`caml_compare`/`caml_lessthan`/`caml_lessequal`/`caml_greaterthan`/`caml_greaterequal`, which raise `Invalid_argument` on functional values), `Binop ((Div | Mod), _, _)`, safe indexing (`StringGet`/`BytesSet`/`ArrayGet`/`ArraySet` with `safe = true`), `CreateBytes`, and `MakeArrayInit` as potentially raising so enclosing `TryWith` handlers retain live values, `CheckExn` unwinds frame values/reuse tokens, and `arc_alloc_bytes`/`arc_alloc_array`/`ocamlcc_weak_*` raise `Invalid_argument` (releasing consumed `init` on invalid array length) instead of aborting. `TryWith` preserves `env.frame_borrowed` alongside `catch_owned` in `try_owned` so raising inside joined expressions keeps borrowed references alive across handler and continuation execution.
- **Cycle collector (`ocamlcc_arc_collect`)**: opt-in Bacon-Rajan trial-deletion collector over candidate roots in `g_cc_roots` (protected by `g_cc_lock` + `g_cc_active`), using a local `TrialMap` table so trial decrements never mutate live `ArcHeader.refcount` values concurrently; `drop_child_val` inside `release_subtree` registers surviving decremented children, and `cc_roots_remove_locked` unregisters dying candidates (including `ARC_TAG_FIBER`, fixing a dangling-root double-free on fiber drops) before `slab_free`. **Fibers are cycle candidates**: the trial treats a fiber's shadow-stack slots, entry closure, resume/suspend payload, and per-fiber exception slots as owning child edges (`cc_visit_children`), so cycles through a suspended fiber's shadow stack (`record -> fiber -> record`) are collected; queued scheduler fibers keep the scheduler's `+1` from `spawn` and survive every trial, and collected fibers have their reuse tokens, stacks, and buffers torn down explicitly in the dead pass while leaf releases and `slab_free` run outside `g_cc_lock`. Regression-probed by `test_fiber_shadow_cycle` in `examples/cycle_collect.ml` and `tests/mt_ffi_host.c`.
- **Weak arrays (`ARC_TAG_WEAK = 249`)**: protected by `g_weak_lock` (`g_weak_head`, `g_weak_count`, `g_weak_targets`); `ocamlcc_weak_get` / `ocamlcc_weak_get_copy` upgrade targets via `arc_try_retain` so concurrently dying targets return `None` instead of resurrecting. Unscanned weak slot arrays are automatically cleared to `0` (`None`) inside `release_subtree` whenever any pointed-to heap object dies (including on `arc_drop_reuse` and when a dying weak array is itself tracked by another weak array after `weak_unlink`). **Drop-time weak clearing is O(1) for objects never weakly referenced**: `weak_set` records every weakly-referenced value in an open-addressing registry (`g_weak_targets` in `runtime/arc.c`, load factor ≤ 2/3 with tombstone reuse so probes always terminate), and `weak_clear_target` only walks the weak arrays when the dying object is registered, removing the entry afterwards — the registry stays proportional to live weak data instead of taxing every heap drop with an O(weak-arrays) scan. Stale entries (a value overwritten out of its slot) cost one wasted lookup. `ocamlcc_weak_get` stays rc-neutral for the slot's uncounted target (retain before wrapping in `Some`, since the caller's field-read retain + `Some` drop + binding release net to −1); `ocamlcc_weak_get_copy` instead returns a fresh one-level block copy (same `tag`/`scan_fields`/`byte_size`, scanned fields retained, **no** wrap-retain — the fresh block's refcount 1 is exactly balanced to one free by the caller), so mutating the copy never reaches the stored element.
