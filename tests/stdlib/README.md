# Native stdlib API regressions

Build with `ninja -j1` and `python3 tools/stdlib_compat.py --skip-tests`, then
run `python3 tools/stdlib_regressions.py`. Select cases by directory name,
for example `python3 tools/stdlib_regressions.py lexing parsing marshal_graph`.
Use `--stock` to check the same sources with the installed OCaml compiler.
The pinned compatibility sources and stock wire fixtures use OCaml 5.5.0.

Each directory contains ordered OCaml units and an `expected` stdout file.
The runner generates real `.mll` and `.mly` inputs with `ocamllex`/`ocamlyacc`,
compiles modules with ocamlcc, links only the compatibility stdlib and ARC
runtime, and checks exit status and stdout. Generated files and complete logs
remain under `build/stdlib_regressions/<case>/`.

The `marshal_wire/expected` hex streams were generated by stock OCaml from the
checked-in source. They cover wire bytes and heap-size headers independently
of our decoder. Other fixtures exercise public roundtrips, sharing/cycles,
channel sequencing/EOF, buffer bounds, and Bigarray views. Functional values
are intentionally rejected; no fixture assumes a portable native code registry.

`tests/stdlib_runtime.c` also checks malformed partial-cycle cleanup,
truncation/mutated streams, successful cycle collection, and backing-buffer
lifetime. It is part of `ninja -j1 test` and `ninja -j1 asan_test`.

Upstream standalone tests run separately with `tools/stdlib_compat.py`.
Their original sources/references remain unchanged under `vendor/`.
